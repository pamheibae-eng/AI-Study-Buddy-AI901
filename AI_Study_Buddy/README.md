# AI Study Buddy

A simple rule-based AI chatbot created as an internship project.

## Technologies
- HTML5
- CSS3
- JavaScript
- No external API
- No API key required

## Features
- Chat interface
- Keyword/intent matching
- AI and machine-learning study responses
- NLP, Computer Vision, Generative AI and Responsible AI topics
- Quick-question buttons
- Clear chat
- Responsive design

## How to run in VS Code

1. Extract the ZIP file.
2. Open the extracted `AI_Study_Buddy` folder in VS Code.
3. Open `index.html`.
4. Right-click `index.html` and choose **Open with Live Server** if the Live Server extension is installed.
5. Or simply double-click `index.html` and open it in a browser.

## How to push to GitHub

Create a new GitHub repository and upload:
- `index.html`
- `README.md`

Or use Git:

```bash
git init
git add .
git commit -m "Add AI Study Buddy chatbot"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## Important

This version is a **rule-based chatbot**, not a large language model. Its responses are selected from a knowledge base using keyword matching. This makes it simple, explainable, and suitable for demonstrating the AI Study Buddy project.
